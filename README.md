# UCT Supa Pool Website

Pool club tournament and player management system.

## Setup
1. Create virtual environment: `python -m venv venv`
2. Activate it: `source venv/Scripts/activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the app: `uvicorn app.main:app --reload`

## Features (Planned)
- Player profiles
- Team profiles
- Tournament management
- Statistics tracking
- Leaderboards
